# Pattern
A pattern grid where you can paint your design and download it , CSS and JavaScript.

## Try It

[Demo Link](https://temi-ay.github.io/Pattern/)

Just open the link and give it a try.

## Features
- Resizable grid
- Colour palette and custom colour
- Mirror Mode
- Local Storage
- download your pattern as a PNG
## How It Works

- **HTML** — the page structure, controls and palette
- **CSS** — styling 
- **JavaScript** — interactivity, 
- **Canvas Api**- for download
